# Code of Conduct

## Our Commitment

We want this repository to be a respectful, practical, and welcoming learning space for contributors and learners across experience levels.

## Expected Behavior

- be respectful in discussions and reviews
- assume good intent and focus on improving the material
- give actionable technical feedback
- welcome beginners without lowering technical standards
- keep conversations centered on learning and building

## Unacceptable Behavior

- harassment, insults, or personal attacks
- discriminatory language or behavior
- deliberate disruption of community discussions
- bad-faith contributions or spam

## Enforcement

Repository maintainers may edit, remove, or reject contributions and comments that do not align with this code of conduct.

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and other project interactions.
