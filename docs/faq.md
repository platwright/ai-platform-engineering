# FAQ

## Do I Need To Be A Data Scientist?

No. This course is for engineers who need to build and operate the platform around AI workloads.

## Do I Need A GPU?

Not for the early modules. The course starts local-first and uses CPU-friendly or hosted paths where possible.

## Is This Only About LLM APIs?

No. The course covers the platform capabilities around model access, RAG, agents, serving, observability, security, reliability, and self-service.

## Can I Skip To Kubernetes?

You can, but it is a poor trade if you do not yet understand how AI workloads differ from ordinary web traffic. Module 00 through Module 03 exist to build that mental model.

## Why Are Some Directories Only Scaffolds Right Now?

The repository is being built progressively. Module 00 is complete, and the remaining areas are scaffolded to match the intended course structure.
