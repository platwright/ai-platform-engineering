## Fast-Track Notes

If you already work heavily with Kubernetes or cloud platforms, Modules 00 through 03 still matter. Those modules establish the AI workload model that later infrastructure decisions depend on. The mental model shift from "containers running web services" to "containers running inference workloads with token budgets, KV caches, and non-deterministic outputs" is the foundation.

If you already have strong LLM API experience, Module 01 will be a quick read but Module 02 on streaming, structured outputs, and tool calling as platform surfaces is worth your time even if you know the API basics.
