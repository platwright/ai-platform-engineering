# Glossary

## AI Platform Engineering

The practice of building shared capabilities that let teams develop and operate AI applications safely and repeatedly.

## Inference

Running a trained model on input to produce an output.

## Model Serving

The runtime system that exposes models through an API and manages request handling, resource usage, and scaling behavior.

## RAG

Retrieval-Augmented Generation. A pattern that retrieves relevant information and injects it into the model context at inference time.

## Embedding

A numeric vector representation of data that enables semantic search and retrieval operations.

## AI Gateway

A shared layer that standardizes model access, routing, credentials, quotas, fallback, and usage tracking.

## MCP

Model Context Protocol. A protocol for exposing tools and resources to models and agent runtimes.

## TTFT

Time to first token. A common latency metric for streaming LLM workloads.

## KV Cache

Cached transformer attention state that improves token generation efficiency but consumes memory.

## SLO

Service Level Objective. A target for service behavior, such as latency or availability.
