# Glossary

## AI Platform Engineering

The practice of building shared capabilities that let teams develop, deploy, serve, observe, secure, and scale AI applications safely and repeatably. Distinct from data science, ML research, and prompt engineering.

## Agent

A system that combines a model, a control loop, tools, state, and policy to take actions rather than only generate text. Operationally, agents require tool authorization, sandboxing, approval gates, state management, and auditability.

## Agent Loop

The repeating cycle where a model receives context, decides whether to call a tool or respond, calls the tool if needed, receives the result, and continues until it produces a final response.

## Attention Mechanism

The transformer component that allows each token to consider the relevance of every other token in the context. Computationally expensive and central to the cost of processing long contexts.

## Autoregressive Generation

The process by which a language model generates one token at a time, conditioning each new token on all previously generated tokens. This is why LLM generation latency scales with output length.

## Batch Inference

Running model inference on many inputs at once rather than one at a time. Improves throughput and GPU efficiency but adds latency for individual requests. Used for offline processing, evaluation, and background tasks.

## BPE (Byte Pair Encoding)

A tokenization algorithm that merges frequent character pairs iteratively to form a vocabulary of subword units. Used by GPT-family models. Means the same word can split differently depending on surrounding context.

## Chargeback

The practice of attributing infrastructure or API costs to the internal teams or products that generated them. In AI platforms, chargebacks typically track token usage or GPU hours by tenant, team, or application.

## Chunking

The process of splitting documents into smaller segments before embedding and indexing for retrieval. Chunk size and overlap directly affect retrieval quality and cost.

## Completion Tokens

The tokens generated by the model as output in a single inference call. Typically billed at a higher rate than prompt tokens by hosted API providers.

## Constrained Decoding

An inference technique that restricts token generation to sequences matching a grammar or schema. Used to enforce JSON structure, regular expressions, or other output formats at the token level rather than in post-processing.

## Context Window

The maximum number of tokens (input plus output) that a model can process in a single inference call. Exceeding the context window causes the request to fail or earlier tokens to be truncated.

## Continuous Batching

A model serving technique that adds new requests to a batch mid-generation rather than waiting for all requests in a batch to finish before accepting new ones. Improves throughput under variable load.

## DPO (Direct Preference Optimization)

A fine-tuning technique that trains a model to align with human preferences without a separate reward model. An alternative to RLHF used for instruction following and behavior alignment.

## Embedding

A dense numeric vector representation of text, images, or other data. Enables semantic similarity search. Produced by a dedicated embedding model, not by a generative LLM. Stored in a vector database.

## Embedding Model

A model trained specifically to produce embeddings, as opposed to a generative model. Examples: OpenAI `text-embedding-3-small`, sentence-transformers, Cohere Embed. Embedding models are typically smaller and cheaper than generative LLMs.

## Evaluation Dataset

A curated set of inputs and expected outputs used to measure model or pipeline quality. In LLMOps, evaluation datasets are version-controlled artifacts that form the basis of automated regression checks.

## Fine-Tuning

Training an already pre-trained model on a smaller, domain-specific dataset to improve its behavior for a specific task. Changes the model weights. Different from prompt engineering, which changes only the input.

## Foundation Model

A large model trained on broad data that can be adapted for many downstream tasks, either by prompting or fine-tuning. Often used interchangeably with "base model."

## Function Calling

See Tool Calling.

## Generative AI

AI systems that produce new outputs (text, images, code, audio, video) rather than only classifying or predicting discrete values. LLMs are the primary generative AI surface in most platform engineering contexts.

## Golden Path

A well-supported, recommended way to accomplish a common task in a platform. Golden paths reduce cognitive load and onboarding friction. In developer platforms, a golden path often takes the form of a template or workflow.

## GPU (Graphics Processing Unit)

Hardware originally designed for graphics rendering that is highly effective for the parallel matrix operations required by neural network inference and training. Primary accelerator in most AI infrastructure.

## Guided Decoding

See Constrained Decoding.

## Hallucination

A model output that is factually incorrect, fabricated, or inconsistent with the provided context, presented with apparent confidence. A reliability concern rather than a correctness guarantee from the model.

## HPA (Horizontal Pod Autoscaler)

A Kubernetes controller that adjusts the number of pod replicas based on metrics. For AI workloads, HPA configurations often use custom metrics like queue depth or GPU utilization rather than CPU.

## Inference

Running a trained model on input to produce an output. The production-facing workload in most AI platform contexts. Distinct from training.

## JSON Mode

A model generation mode that constrains output to syntactically valid JSON. Stronger than prompting the model to "return JSON" but weaker than schema-constrained generation.

## KV Cache (Key-Value Cache)

Memory that stores the intermediate attention states computed during inference. Allows the model to reuse prior computation rather than recalculating attention for all previous tokens on each generation step. The primary driver of GPU memory consumption in model serving.

## LLM (Large Language Model)

A foundation model trained on large text corpora to perform language tasks including generation, summarization, classification, code completion, and conversation.

## LLM-as-Judge

An evaluation pattern where a language model assesses the quality of another model's output. Useful for evaluating open-ended responses where exact-match scoring is insufficient.

## LLMOps

The operational practices around managing language models in production: prompt versioning, evaluation pipelines, regression testing, model lifecycle management, and AI CI/CD.

## MCP (Model Context Protocol)

A protocol for exposing tools and resources to models in a discoverable, standardized way. Allows platform teams to govern what tools agents can discover and call without hard-coding tool lists in every application.

## MIG (Multi-Instance GPU)

An NVIDIA technology that partitions a single GPU into multiple isolated instances, each with dedicated memory and compute. Improves utilization and isolation when multiple small workloads share a GPU.

## Model Serving

The runtime system that loads model weights, exposes an API endpoint, handles request batching and scheduling, manages GPU memory, and returns inference results. vLLM, TGI, and Triton are examples.

## Multi-Tenancy

The practice of serving multiple isolated customers or teams from shared infrastructure. In AI platforms, multi-tenancy requires explicit tenant isolation in RAG indexes, tool access policies, and usage attribution.

## Ollama

A local model serving tool that makes it easy to run open-weight models on developer machines. Used in this course for development and low-scale local testing.

## Online Inference

Real-time inference serving individual requests as they arrive, with latency requirements. Distinct from batch inference.

## Open-Weight Model

A model whose trained weights are publicly released. Note: open-weight is not the same as open-source. Some open-weight models have restrictive commercial licenses.

## PagedAttention

A KV cache memory management technique used by vLLM that allocates cache memory in non-contiguous pages, dramatically reducing waste and enabling higher serving concurrency.

## Parallelism (Tensor, Pipeline, Data)

Strategies for distributing model inference across multiple GPUs. Tensor parallelism splits layer computations across GPUs. Pipeline parallelism splits layers sequentially. Data parallelism runs independent replicas.

## Perplexity

A measure of how well a language model predicts a text sample. Lower perplexity means the model assigns higher probability to the test text. Used as a quality metric in model evaluation.

## Prompt

The input sent to a language model. In production systems, prompts are composites of system instructions, retrieved context, conversation history, and the current user turn. Prompts are operational artifacts that need versioning and governance.

## Prompt Caching

Reusing the KV cache state for a repeated prefix across multiple requests. Reduces compute cost for system prompts that appear identically in many requests.

## Prompt Injection

An attack where malicious content in user input or retrieved data overrides system instructions, causing the model to take unintended actions. A primary security concern for AI applications with tool-calling or action-taking capabilities.

## Quantization

Reducing the numeric precision of model weights (e.g., from FP16 to INT8 or INT4). Reduces memory footprint and can improve throughput at the cost of some output quality degradation.

## RAG (Retrieval-Augmented Generation)

A pattern that retrieves relevant documents or chunks from an external store and injects them into the model context at inference time. Allows models to answer questions about information not present in their training data.

## Reranker

A model or scoring function that reorders retrieval candidates by relevance after initial vector search. Improves retrieval precision by applying deeper semantic comparison than vector similarity alone.

## RLHF (Reinforcement Learning from Human Feedback)

A fine-tuning approach that uses human preference judgments to train a reward model and then optimizes the language model to maximize that reward. Used to align models with intended behavior.

## Semantic Caching

Caching model responses based on semantic similarity of requests rather than exact request text. Allows cache hits for paraphrased questions. Introduces correctness risk because semantically similar is not semantically identical.

## SLI (Service Level Indicator)

A quantitative measure of service behavior. For AI systems, SLIs include TTFT, token throughput, error rate, retrieval success rate, and evaluation scores.

## SLO (Service Level Objective)

A target value or range for a service level indicator. For example: 95% of requests have TTFT < 800ms. SLOs define the reliability contract for a service.

## System Prompt

The instruction prefix sent to the model that establishes its role, constraints, and behavior. System prompts are platform-level artifacts and should be versioned, reviewed, and treated with the same discipline as application code.

## Temperature

A generation parameter that controls the randomness of token sampling. Low temperature produces more deterministic, focused output. High temperature produces more varied, creative output.

## Tensor Parallelism

See Parallelism.

## TGI (Text Generation Inference)

Hugging Face's high-performance LLM serving framework. Supports many open-weight models and provides an OpenAI-compatible API surface.

## Time to First Token (TTFT)

The elapsed time from when an inference request is sent until the first output token is received. The primary latency metric for interactive LLM applications.

## Tokenization

The process of converting raw text into a sequence of integer IDs (tokens) that the model processes. The tokenizer is trained alongside the model and is specific to each model family.

## Tool Calling

The mechanism by which a model can request execution of an external function and receive the result. Also called function calling. Turns models from text generators into action-capable systems, introducing authorization, sandboxing, and auditability requirements.

## Top-P (Nucleus Sampling)

A generation parameter that restricts token sampling to the smallest set of tokens whose cumulative probability exceeds the threshold `p`. Produces more coherent output than top-k alone.

## Vector Database

A storage system optimized for storing and querying high-dimensional embedding vectors by similarity. Examples: Chroma, Qdrant, Weaviate, Pinecone, pgvector.

## vLLM

A high-performance open-source LLM serving engine that implements PagedAttention for efficient KV cache management. Exposes an OpenAI-compatible API and is widely used for self-hosted model serving.

## Zero-Trust

A security model that does not assume trust based on network location. Every request must be authenticated and authorized regardless of where it originates. Important for AI platform design because agents and tools cross many service boundaries.
