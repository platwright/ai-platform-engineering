# Applications

This directory holds sample applications used to exercise the platform and connect the course modules to concrete runtime surfaces.

## Current Status

- [sample-chat](sample-chat/README.md): complete
- [sample-rag](sample-rag/README.md): complete
- [sample-agent](sample-agent/README.md): complete

## Purpose

These applications are intentionally small. Their job is to make platform concerns visible:

- what the application API looks like
- how prompts and configuration enter the request path
- where provider abstraction sits
- what needs to be containerized, deployed, observed, and secured later
