# Module 10 Challenge

## Challenge Prompt

Acme AI wants to let internal engineers use an agent to inspect platform services, but the security team is worried about unsafe tool use and the operations team is worried about opaque behavior.

Design the first safe agent platform policy.

## Deliverable

Create a note in:

- `my-solutions/module-10-agent-policy.md`

Include:

1. which tools are safe by default
2. which tools require approval
3. which state the agent should retain
4. what audit record is required for every run
5. what sandbox or isolation expectations you would add first
