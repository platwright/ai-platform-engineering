# Solutions

This directory holds curated reference solutions for module labs and challenges.

## Status

Solutions are authored progressively alongside module content. Where a module is complete, a corresponding solution reference can be found in the module's own `solution.md` file.

This directory will consolidate solution artifacts that are:

- runnable code (scripts, config files)
- expected run artifact samples
- reference architecture diagrams
- challenge model answers

## Using Solutions

Solutions exist to help when you are stuck, to verify your own work, and to show one defensible approach among several possible approaches. They are not the only valid answer.

Try the lab or challenge yourself first. Reviewing solutions without attempting the work first significantly reduces the learning value.
