# Roadmap

## Goal

Build a free, public course repository that takes learners from AI platform fundamentals to a production-oriented internal AI platform narrative.

## Delivery Phases

### Phase 1 - Foundation

- repository structure
- course guide and prerequisites
- contributor guidance
- Module 00 completed

### Phase 2 - Foundational Learning Path

- Module 01 - AI Foundations
- Module 02 - LLM Foundations
- Module 03 - AI Application Architecture
- Project 01 - Unified Model Client

### Phase 3 - Platform Runtime

- Module 04 - Containers and AI Workloads
- Module 05 - Kubernetes for AI
- Module 06 - GPU and Accelerators
- Module 07 - Model Serving
- Project 02 - Open model serving on Kubernetes

### Phase 4 - Shared Platform Capabilities

- Module 08 - AI Gateway
- Module 09 - RAG Platform
- Module 10 - Agent Platform
- Project 03 - RAG as a Service
- Project 04 - Safe Agent Platform

### Phase 5 - Production Operations

- Module 11 - LLMOps
- Module 12 - Observability
- Module 13 - Security
- Module 14 - Reliability
- Module 15 - Scaling and Performance
- Module 16 - AI FinOps

### Phase 6 - Platform Productization

- Module 17 - Developer Platform
- Module 18 - Capstone
- Final AI Platform project
