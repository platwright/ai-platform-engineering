# Contributing

## Purpose

This repository is intended to become a high-quality public learning resource for AI platform engineering. Contributions should improve clarity, correctness, practical value, or hands-on usability.

## Good Contributions

- fix incorrect instructions or broken commands
- improve explanations without increasing unnecessary complexity
- add validation steps that make labs more reliable
- add diagrams that clarify architecture or failure modes
- add references that materially improve a module

## Keep Changes Focused

Please prefer small, focused pull requests. A single pull request should ideally change one of the following:

- one module or chapter
- one lab
- one project scaffold
- one documentation area
- one validation or automation script

## Repository Conventions

- favor concept-first explanations before product-specific tooling
- preserve the local-first learning path when adding early material
- align new material to the Acme AI narrative when possible
- prefer reproducible steps over hand-wavy instructions
- add verification guidance whenever you add a lab or workflow

## Workbook Content

Learners are encouraged to keep `progress/`, `my-notes/`, and `my-solutions/` in their own forks.

Please do not submit personal workbook content to the upstream repository unless it has been rewritten as generally useful course material.

## Style Guidance

- use plain, direct language
- keep examples production-relevant
- separate required steps from optional exploration
- explain failure modes when they are operationally important

## Before Opening A Pull Request

1. Check links and referenced paths.
2. Run any new validation script you added.
3. Make sure examples are consistent with the module narrative.
4. Confirm you did not add unrelated changes.
